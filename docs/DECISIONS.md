# 架构决策记录

## ADR-001：通用发现是默认路径

日期：2026-08-30

决定：未知网站直接读取可见 DOM 并生成通用映射；适配器只作为可选结构缓存，指纹失效时
自动降级 generic。

原因：站点数量和页面变体不可控，维护每个网站的专用映射不能泛化；共享发现、共享字段本体
和安全状态机可以覆盖更多页面并减少重复配置。

代价：未知页面的字段语义和复杂控件成功率会低于专用适配器，因此必须输出置信度并保留人工接管。

## ADR-002：动态记录在动作后重新读取

决定：预览阶段不点击添加；用户确认后只创建所需空白记录，动作完成后废弃旧 locator 并重新读取。

原因：动态 DOM 会使预先复制的定位器失效，错误记录比漏填更危险。

## ADR-003：不追求无提示的全自动提交

决定：提交、保存、投递、附件上传、登录和验证永远不由系统执行。

原因：这些动作具有不可逆外部副作用或需要用户承担内容与身份责任；项目目标是安全辅助填写，
不是无人值守投递机器人。

## ADR-004：模型只提供候选，不改变安全状态机

决定：未来模型可补充词典未覆盖的语义候选，但必须返回解释、置信度和候选路径；模型不能绕过
用户确认、敏感字段和 no-submit 规则。

原因：模型有助于提高泛化，但不可审计的自动猜测会放大误填和隐私风险。
